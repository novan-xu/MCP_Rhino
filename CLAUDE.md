# CLAUDE.md

This repository's operating rules for AI agents live in [`AGENTS.md`](./AGENTS.md). Load it at the start of every session before taking any action.

`AGENTS.md` is the single source of truth; it in turn points to the authoritative rule files under `Project_Guides/` and `Workflow/`, and specifies the boot protocol (including reading the cross-session activity log in `log/`). Do not restate those rules here — always read the current `AGENTS.md`.
