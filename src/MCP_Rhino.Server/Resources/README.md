# MCP_Rhino Resources

This directory is reserved for MCP resources that expose reference-only content.

Resources may provide static or generated documentation such as RhinoCommon notes,
RhinoScript references, modeling policy text, or generated tool help. They must not
inspect, query, export, preview, or mutate the live Rhino document.

Executable Rhino behavior belongs under `Tools/`, reusable workflows under
`Skills/`, and goal-driven routing under `Agents/`.
