# Reference Image Primitive Decomposition

Turn the model brief into buildable abstract primitives.

Use general primitive vocabulary:

- box or rounded box
- sphere or ellipsoid
- cylinder, cone, capsule, pipe, torus
- panel, extrusion, sweep, loft
- boolean cutter
- raised strip
- decal plane
- material-only cue

For each part, provide a preferred primitive, fallback primitive, rough local transform, role, edge treatment intent, and required tool family.
