# Reference Image Model Brief

Convert the visible reference image into a structured object brief before any Rhino mutation.

Required outputs:

- object type, confidence, primary target object
- viewpoint and hidden-depth assumptions
- width/depth/height relationship
- major parts and parent-child hierarchy
- soft, hard, or mixed edge character per part
- visible seams, holes, handles, supports, labels, repeated details
- dominant material and color cues
- unknowns and risky assumptions

Do not choose exact Rhino commands in this step.
