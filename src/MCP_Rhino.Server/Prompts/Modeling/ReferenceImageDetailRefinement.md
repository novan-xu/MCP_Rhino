# Reference Image Detail Refinement

Plan refinements only after initial massing and visual QA.

Prefer geometry for:

- silhouette-changing handles, legs, supports, rims
- readable seams, ribs, borders, bezels
- true holes, slots, cutouts

Prefer material or texture for:

- fabric grain
- color variation
- printed patterns
- roughness or gloss differences

Do not add detail geometry that creates clutter without improving object recognition.
