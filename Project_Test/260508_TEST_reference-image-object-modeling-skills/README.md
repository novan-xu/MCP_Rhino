# Reference Image Object Modeling Skills Smoke

## Purpose

Validate the first deterministic skills slice for reference-image object modeling:

- structured model brief construction
- primitive decomposition across multiple object categories
- initial massing live-only execution handoff
- detail refinement planning
- material planning
- iteration decision policy

## Commands

CLI fallback:

```powershell
dotnet run --project src\MCP_Rhino.Server\MCP_Rhino.Server.csproj -c Debug --no-build -- reference-image-object-modeling-skills-smoke-test
```

Live Rhino smoke:

```text
_McpReferenceImageObjectModelingSkillsSmoke
```

The live command requires a saved active Rhino document and a loaded MCP_Rhino plugin.
