# Material Texture Capability Test

## Purpose

Record validation for the material texture capability, including procedural texture generation, textured material routing, texture mapping routing, prompt policy, and agent execution guards.

CLI fallback validation reaches the live-Rhino boundary for document mutations. Live Rhino validation should run the same MCP tools through the Debug bridge or Release panel-bound pipe against a saved active document.

## Checks

- `Project_Plan/260509_PLAN_material-texture-capability.md` exists and covers textured material creation, procedural texture image generation, texture mapping, safety annotations, and agent routing policy.
- `src/MCP_Rhino.Server/Prompts/Modeling/ReferenceImageObjectModelingAgent.md` tells the reference-image object modeling agent not to model material, texture, lighting, or shadow cues as geometry.
- `src/MCP_Rhino.Server/Domain/Rules/ReferenceImageVisualCueGeometryPolicy.cs` classifies material, texture, lighting, highlight, and shadow cues as non-geometry while allowing true seams.
- `src/MCP_Rhino.Server/Application/Services/ReferenceImageDetailRefinementPlanningService.cs` suppresses non-geometry visual cues before they become detail actions.
- `src/MCP_Rhino.Server/Agents/Modeling/ReferenceImageObjectModelingAgent.cs` refuses to execute non-geometry visual cues as simple raised strips.
- `GenerateProceduralTextureImage` can create a deterministic woven PNG file.
- `CreateTexturedRenderMaterials`, `InspectRenderMaterialTextures`, `PreviewTextureMapping`, and `ApplyTextureMapping` are MCP tools with explicit safety annotations.
- `DeveloperCommandHandler.MaterialTextureCapabilitySmokeTest.cs` verifies weave, cast shadow, and highlight suppression, verifies that a real raised seam still becomes geometry, creates a woven PNG, and checks that textured material/mapping routes reach the live-Rhino boundary in CLI fallback mode.
