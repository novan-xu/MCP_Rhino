## Commands

From the repository root, with Rhino 8/Grasshopper and .NET 8 installed:

```powershell
& './Project_Test/261010_TEST_stone-bake-lintels/Run-Validation.ps1' -ScriptPath '<linked-or-staged-script>' -Configuration Debug
& './Project_Test/261010_TEST_stone-bake-lintels/Run-Validation.ps1' -ScriptPath '<linked-or-staged-script>' -Configuration Release
dotnet run --project './Project_Test/261010_TEST_stone-bake-nested-outlines/NativeChecks.csproj' -c Release -- '<staged-router-exe>' '<source-dwg>' '<linked-or-staged-script>' './Project_Test/261010_TEST_stone-bake-nested-outlines/ValidateBake.csx' '<settings-json>' '<report-json>'
```

Native settings JSON contains `fin`, `flat`, and `lintel`, each with numeric `offset` and `height` fields in inches. The source must contain eligible visible assemblies. `ValidateBake.csx` additionally expects source plan baselines at Z=0 within 1e-6 model inches, as in this batch.

The client uses the supported Router transport and `rhino_offline_preview_rhino_script`. It creates synthetic definitions only inside the disposable headless preview document, then tests the actual drawing bake. It never applies the preview or publishes its fixtures.

## Results — 2026-10-10

All commands above passed (exit 0), using staged Router 1.3.5 and Rhino 8.35.26251.13001. Debug/Release validation covered full script compilation/emit with five GH bindings, setup compilation, all existing missing-only, source visibility, identity, geometry transform, lintel, and Undo ownership regressions. The deployed script is byte-identical to the tested staged file.

The native checks passed 12 assertions:

- Direct polyline, nested translation, rotation before horizontal classification, and mirrored nonuniform scaling.
- Multiple levels with noncommuting transforms; repeated shared definitions on separate paths; coincident duplicates; mixed direct/nested edges.
- Ambiguous edges rejected, an actual 24-level chain rejected, a seeded active recursion path rejected as cyclic, and a singular transform rejected.
- Across all cases, member geometry CRCs, complete attributes, object counts, and definition counts remained unchanged during outline collection.

Native actual-row-6 preview and subsequent production apply each baked 130 fins and 115 flats into 115 assembly instances (36 new definitions). All 28,299 imported persistent objects were preserved. A second bake added zero objects/definitions. The 40 assemblies without eligible visible nested stones were skipped by the existing visibility/family scope.

Row 6 settings: fins Z=382.59808, height=44.15192; flats Z=383.75278, height=42.99722 inches. Values were read at full workbook precision. Saved coordinates and dimensions passed tolerance 1e-6 inches.

The completed batch was reopened and independently checked with Rhino3dm: 18 outputs, 796 fins, 761 flats, 266 lintels (1,823 surfaces), 1,021 assembly instances. Original DWG/workbook hashes and previous 17 output hashes match their recorded values. Saved family counts, source identities, member metadata, base elevations, heights, and inch units passed.
