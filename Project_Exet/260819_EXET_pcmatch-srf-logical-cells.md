## Execution result / actual scope

- Renamed the public Rhino command from `PCMatch` to `PCMatchSrf`. No `PCMatch` command alias remains registered.
- Narrowed compatibility to the ordered cladding cell codes generated by each panel's H/V divider counts.
- Panel dimensions, geometry class differences among supported projections, numeric H/V offset values, segment masks, and merge masks are ignored for compatibility.
- Removed the source type/signature requirement and allowed a source with no explicit cell keys.
- Source material and parent-cell references are still validated. Blank cells are accepted; invalid references and cycles remain fail-closed.
- The match plan now writes/deletes cladding-cell keys only. Missing source assignments use the Rhino-retained blank representation.
- Target offsets, masks, type/signature, identity metadata, and unrelated attributes remain untouched.
- Retained batch fail-closed behavior: one target with a different generated cell-code lattice rejects the full plan before Rhino mutation.
- Bumped PanelCladdingEditor to `1.0.47`, packaged, installed, and validated its current-user Rhino 8 registration.
